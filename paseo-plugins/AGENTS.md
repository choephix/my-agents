# Paseo plugins

Each folder here is one Paseo plugin. Its `OVERVIEW.md` is the truth about what it does: read it
before changing the plugin, and update it with any behaviour change.

Efforts for this work (plans, briefs, notes, measurements) live in `.scratch/<effort>/` in this
folder. Before any work, read `.scratch/README.md`: it holds the private paths and rules.

`.scratch/` is private: this repo is public, so `.scratch/` is gitignored and the pre-commit hook
refuses it. Never force-add it, never copy its content into tracked files.
