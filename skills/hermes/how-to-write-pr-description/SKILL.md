# How to Write PR Descriptions

Write PR descriptions from the reviewer’s context, not our conversation context.

Be extremely concise, precise, and high-signal: short direct sentences, concrete nouns/verbs, no filler, no throat-clearing, no process narration.

Mostly freeform; use bullets/sections only when they clearly improve scanability, avoid otherwise.

Feel free to sacrifice grammar for the sake of clarity and concision.

Describe the final diff/behavior plus only the rationale, risks, and testing the reviewer needs.

Do not include process history, reverted/discarded work, private chat context, or template sections that don’t add value.
